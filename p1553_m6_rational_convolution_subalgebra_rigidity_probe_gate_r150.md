## Ambient quotient theorem

For prime `q`, the characteristic-zero cyclic convolution algebra is

```text
A = Q[C_q] = Q[X]/(X^q-1).
```

The Chinese remainder theorem and prime cyclotomic irreducibility give

```text
A = Q direct-product Q(zeta_q).
```

The factors are fields. Consequently, a nonzero unital rational algebra
quotient has dimension `1`, `q-1`, or `q`. The one-dimensional quotient is
augmentation, evaluation at `X=1`; it retains total mass and discards every
nonconstant cyclic component.

The actual controls include same-size shifted decks whose selected C6
counts differ. They make the augmentation failure explicit, but verifier
labels receive no candidate or asymptotic credit.

## Actual deck theorem

Encode the proper binary deck as

```text
U(X) = sum_(a in C) X^a
```

and define its multiplicative stabilizer

```text
H_C = {k in F_q^*: kC=C}.
```

The Galois conjugates of `U(zeta_q)` satisfy

```text
U(zeta_q^k) = U(zeta_q^l) iff kC=lC.
```

For the nontrivial direction, reduce the binary coefficient difference
modulo `X^q-1`. It has degree below `q`, is divisible by `Phi_q`, and has
coefficient sum zero. A multiple of

```text
Phi_q = 1 + X + ... + X^(q-1)
```

with coefficient sum zero must be zero.

Therefore:

```text
[Q(U(zeta_q)):Q] = (q-1)/|H_C|.
```

If `C` contains a nonzero atom, every nonzero `H_C` orbit inside `C` has
size `|H_C|`. Thus:

```text
|H_C| <= |C|,
dim Q[U] >= (q-1)/|C|.
```

The exceptional constant deck `C={0}` is outside the campaign families.
All eight actual finite decks have trivial stabilizer, although only the
universal deck-size bound receives asymptotic interpretation.

## Cost gate

At the R115 scaling:

```text
q = B^(5+o(1))
|C| = B^(3/4+o(1)).
```

Hence every reusable characteristic-zero multiplication-closed
representation containing the campaign deck has dimension at least

```text
(q-1)/|C| = B^(17/4-o(1)).
```

This exceeds:

```text
setup cap: B^(9/4+o(1))
rho:       B^(5/2+o(1)).
```

With trivial multiplier stabilizer the dimension is `q-1=B^(5+o(1))`,
but R150 does not assume that for the generic-prime family.

## Scope

The theorem covers rational algebra quotients and the reusable
multiplication-closed subalgebra generated by the actual deck. It allows
nonlinear convolution products and arbitrary powers within that state.

It does not cover:

- a bounded-depth circuit specialized only to the sixth power;
- target-specific intermediate objects not closed under convolution;
- adaptive RAM or cell-probe structures;
- bounded-error or nonhomomorphic encodings;
- implicit summation-polynomial or FFE elimination.

The derivation is elementary and novelty-unverified. It is not presented
as an unconditional arithmetic-circuit, data-structure, or generic-group
lower bound.
