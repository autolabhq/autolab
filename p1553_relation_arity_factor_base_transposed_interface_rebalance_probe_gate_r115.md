# P1553 R115 relation-arity/factor-base rebalance gate

## Scope

R115 freezes the rational exponent model requested by R114 before any new
finite instance. It varies the number `m` of Cartesian factor-base points in
a relation and the deck exponents

```text
|A|=B^(alpha+o(1)), |C|=B^(beta+o(1)), alpha<=beta,
F=A+C, N=B^(5+o(1)).
```

It preserves the exact R82 local `3F=3A+3C` membership compiler and asks
when the first R114 transposed source interface can fit the fresh-work cap.
This is a necessary exponent screen, not a source-locator construction.

## Frozen inequalities

For an `mF=R` relation, the expanded atom body has exponent
`m(alpha+beta)`. The density retry exponent and meaningful structured log
rank are

```text
delta=max(0,5-m(alpha+beta)),
d=max(alpha,beta)=beta.
```

The first typed transposed interface, density-adjusted fresh work,
conditional relation collection, and sparse linear algebra are charged as

```text

delta+w1<=5/4,
beta+delta+w1<=9/4,
2 beta<=9/4.
```

Preserving the R82 local compiler additionally requires

```text

```

All quantities are evaluated with exact rational arithmetic.

`w1>5/m>=5/4`. For `m=5`, `w1<=5/4` forces
`alpha<=1/16` and `beta>=15/16`, so `3 beta>=45/16>9/4`.

The first joint witness is


`deg_x S_n=2^(n-2)`. Fixed degree has zero `B` exponent but is not free.

## Missing constructor

The exact balanced split is

```text

```

with `B^(5/2)` work and state on both sides. It is Pollard-rho scale and
misses both campaign caps. The prefix occurrence profile also exceeds the
online cap at the second C atom and setup at the third.

Thus the conditional `B^(9/4)` envelope has no algorithm behind its central
assumption. The missing object is an exact implicit `3F` self-convolution
that finds and opens

```text

```

without enumerating `B^(5/2)` half occurrences. Relation independence,
known-RHS rank, factor logs, and identical target descent remain unproved.

## Disposition

Admit the `m=6`, `alpha=1/12`, `beta=3/4` vertex as a necessary exponent
envelope only. It is neither a relation algorithm nor evidence of a Shoup
improvement.
