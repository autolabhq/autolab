# Planned idea-experiment artifacts

Hypothesis files name planned roots as `ideas/artifacts/ECDLP-IDEA-<NNN>/`. Planned run
roots are created only when an approved experiment is implemented, and a planned path is
not an observed artifact. Immutable theorem derivations and proof-preflight notes may be
preserved before experiment approval when they are explicitly labelled non-run evidence;
their existence neither dispatches an experiment nor changes the hypothesis status.
