# Hypothesis

Retained single-hit-root FFE hyperplanes are not just a factor-shape signal.
On fresh transfer windows 152-175, the retained below-rho surfaces should replay
into verifier-facing relation events that publicly derive the target key under
the same shared transfer challenge seed.

This is a narrower claim than a full ECDLP index-calculus algorithm.  The row
and leaf keys still come from the already-positive fixed-selector signature
cases.  The test is whether filtering those cases down to retained
single-hit-root surfaces preserves the actual relation algebra.
