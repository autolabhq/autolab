# Hypothesis

Compact fixed-target witnesses can be promoted from a post-hoc salt-window
observation to a public window policy.

The earlier future-witness stress probe showed a two-target positive on salts
228-235 and a disjoint negative on 236-243. The next question is whether
public pre-verification features can rank unseen rolling windows before
two-equation pair derivation. The policy should use only row materialization
outputs such as relation-event density, same-term-signature repetitions, and
public filter cost. Derived secrets and pair verification are labels only.
