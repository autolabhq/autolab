# Hypothesis

The 152-175 single-hit-root replay showed that retained root hyperplanes can
carry real verifier relation algebra when the row/leaf keys come from already
positive signatures.  The next test asks whether a fresh public assembly rule
can select useful relation systems before looking at public-key verification.

For transfer indices 176-183, the preregistered rule is:

1. Generate fixed-selector low-term-total2 public leaf candidates.
2. Keep all public below-rho candidates, not only verifier positives.
3. Gate FFE surfaces by the pre-factor single-hit-root proxy.
4. Factor only gated surfaces.
5. Select assemblies whose unique pre-factor hit root recovers a public-zero
   root hyperplane below the rho proxy.
6. Replay the selected assemblies through the verifier.

The selection rule forbids public-key verification, relation count, rank,
preserving-factor labels, false-positive labels, and preserving-conditioned
below-rho labels.
