# Hypothesis

The externally trained `learned_global_zero_root_prior` selected from <=87
pre-factor-gated surfaces can be preregistered before a new 96-103 window and
used as the first non-post-hoc learned root policy for fresh first-fall FFE
surfaces.

The experiment order is fixed by
`ffe_learned_root_prior_preregistration_96_103.json`:

1. declare the 96-103 holdout window;
2. generate fixed row/leaf stress outputs;
3. aggregate only strict verifier-backed below-rho signatures;
4. apply the pre-factor gate before Sage factorization;
5. factor only gate-selected surfaces;
6. audit root-hyperplane shape;
7. score `learned_global_zero_root_prior` trained only on <=87 gated surfaces.

Success requires preserving selected root pairs, zero false positives, and
below-rho scan or direct-root accounting on the new gate-selected surfaces.
